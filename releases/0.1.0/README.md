# Paquete de prueba 0.1.0

`re4bridge-0.1.0-windows.zip` contiene el mod Fabric para Minecraft Java 1.21.1,
Fabric API y el simulador local. No conecta todavía con RE4.

Para descargar desde GitHub, abre el ZIP y pulsa **Download raw file**.
Extrae el paquete y sigue su README. El checksum está en `SHA256SUMS.txt`.

El código fue compilado y pasó 11 pruebas automatizadas. La prueba gráfica
en el Windows del usuario sigue pendiente. No incluye archivos de RE4.
